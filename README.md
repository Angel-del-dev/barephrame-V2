# 🪏 Barephrame V2
Barephrame is a `PHP` framework focused in fast and
efficient `API` development

# ✨ Key Features
+ 🚫 Zero dependencies
+ 🖥️ Its own ORM
+ ✉️ Its own Email service
+ 🚄 Fast response times

# 🚀 Philosophy
Barephrame is built around a simple idea:
> It shouldn't be required to load thousands
of dependecies just to create a robust api.

It is also simple to extend or modify 
core behaviour.
