# 📚 Barephrame V2 Documentation

Welcome to the documentation for **Barephrame V2**, a dependency-free PHP 8.5+
framework focused on fast and efficient API development.

This documentation is organized by topic so it's easy to navigate as the
project grows. If something isn't documented yet, open an
[issue](https://github.com/Angel-del-dev/barephrame-V2/issues) or feel free to open
a pull request.
